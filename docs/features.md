# 機能一覧

このページは、実装済み機能、追加設定が必要な機能、未実装範囲を区別します。

## 風場エディター

| 機能 | 状態 | 補足 |
| --- | --- | --- |
| 地図上のドラッグ入力 | 実装済み | 吹いていく向き、0〜30 m/s |
| 複数制御点 | 実装済み | JSON読込みは最大1000点 |
| IDW連続補間 | 実装済み | NED成分を補間、power 1〜4 |
| 数値編集 | 実装済み | 水平風速、向き、高度 |
| 元に戻す・やり直す | 実装済み | 画面内で最大100状態 |
| ブラウザ内の自動保存 | 実装済み | 同一オリジンのlocalStorage |
| ANEMO JSON入出力 | 実装済み | スキーマ版1 |
| 制御点CSV出力 | 実装済み | 補間設定は含まない |
| PostgreSQL保存 | 追加設定が必要 | Docker・マイグレーション・設定ファイル |
| スマートフォン・タブレット操作 | 基本対応 | 機種別の網羅試験は未実施 |

## FlightEnvironmentEmulator連携

ANEMO JSONはWGS84位置とNED風ベクトルを保存します。FlightEnvironmentEmulator側の自動読込み、位置補間、対気速度への反映、ログ出力は未実装です。現在のJSON書き出しは、連携実装で使う入力仕様を安定させる役割を持ちます。

連携の受入試験には、少なくとも次を含める必要があります。

- 無風場で従来の無風結果と一致する
- 一定向かい風・追い風で対気速度の変化方向が正しい
- 横風で横滑り角の符号が正しい
- 制御点上でANEMO JSONのNED成分と一致する
- 同じJSONと初期条件で同じ結果を再現する
- 読込み失敗時に無風へ戻すか停止し、ログへ理由を残す

## 制約

- IDWは観測物理や地形効果を自動的に満たしません。
- 地図上の矢印密度は表示解像度であり、計算格子ではありません。
- OpenStreetMapタイルの提供状態により地図画像が表示されない場合があります。
- データベースの既存 `wind_direction` には、旧版で向きの定義が明記されていないデータが含まれる可能性があります。新規保存値は「吹いていく向き」です。
- `batch_gpv_wind` は気象庁MSMデータを加工します。取得元、対象時刻、加工内容、利用条件を成果物へ記録してください。
