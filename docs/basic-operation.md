# 基本操作

ANEMOの風場エディターは、少数の制御点を地図上へ置き、その間を連続的に補間して風場を作ります。

![ANEMO風場エディターの操作画面。左に操作欄、右に風場を作る地図がある](../wind_generator/public/images/anemo-wind-field-editor.webp)

画面左側で操作を選び、右側の地図へ風を配置します。画像は説明用の合成データです。地図 © OpenStreetMap contributors

## 起動と終了

```bash
cd ANEMO/wind_generator
npm start
```

ブラウザで <http://localhost:3000> を開きます。終了時はターミナルで `Ctrl+C` を押します。

## 風を追加する

1. 「風を追加」を選ぶ。
2. 地図上で始点を押す。
3. 風が吹いていく向きへドラッグする。
4. 希望する長さで離す。

ドラッグの始点が風を定義する位置です。ドラッグ方向が水平風向、長さが水平風速になります。入力は0〜30 m/sに制限されます。

地図を移動するときは「地図を移動」を選びます。地図を移動・拡大しても、登録済みの風速は変わりません。

## 風を選択・編集する

緑色の矢印、始点の丸、または下の表の行を選びます。選択中の風は橙色になります。

| 項目 | 単位・範囲 | 意味 |
| --- | --- | --- |
| 水平風速 | 0〜30 m/s | 地表面に平行な風の大きさ |
| 吹いていく向き | 0〜360°未満 | 真北0°、東90°、時計回り |
| 高度 | -1000〜100000 m | WGS84位置に付随する高度 |

値を変更して入力欄からフォーカスを外すと反映されます。現在の画面操作は水平風を対象とし、下向き成分は0 m/sで新規作成されます。

## 補間結果を見る

青色の矢印は制御点から計算したプレビューです。逆距離加重（IDW）でNED成分を補間します。

「補間の局所性」を大きくすると近い制御点の影響が強くなります。値を小さくすると遠い制御点も広く影響します。制御点上では、その制御点の値をそのまま使います。

青色矢印は表示用のサンプルです。JSONには制御点と補間設定を保存し、画面上のサンプル格子は保存しません。

## 元に戻す・やり直す

- 「元に戻す」: 直前の追加、削除、数値変更、補間変更を戻す
- 「やり直す」: 戻した操作を再適用する
- 「すべて消す」: 確認後に全制御点を削除する。直後なら「元に戻す」で復元できる

履歴は現在開いている画面内で最大100状態です。ページを再読み込みすると履歴は消えますが、最新状態は自動復元されます。

## ファイルへ保存する

### JSON

「JSONを書き出す」は、単位、座標系、NED成分、補間設定を含む正式なANEMO風場ファイルを作ります。編集の継続、受渡し、将来のFlightEnvironmentEmulator連携にはJSONを使用してください。

### CSV

「CSVを書き出す」は制御点の一覧を表形式で作ります。補間方法、作成日時、データ形式版は含まれません。表計算や確認用です。

### 読込み

「JSONを読み込む」で `*.anemo.json` を選びます。ANEMOは次を検査し、不正なファイルを拒否します。

- スキーマ名と版
- WGS84、NED、向きの定義
- 緯度、経度、高度、風速の範囲
- 制御点IDの形式と重複
- 最大1000制御点、最大1 MB

読込みに失敗した場合は、元の作業状態を維持します。

## ブラウザ内の自動保存

最新の風場は同じブラウザのローカルストレージへ保存されます。サーバーや外部サービスへの自動送信は行いません。地図タイルを表示すると、ブラウザからOpenStreetMapのタイルサーバーへ地図画像のリクエストが送られます。

## データベースへ保存する

データベースが起動・設定済みの場合、「データベースへ保存」を開いて測定グループIDと日時を指定します。全制御点が1つのトランザクションで保存されます。途中で失敗した場合は全件をロールバックします。

データベースが停止していても、JSON・CSVとブラウザ内の作業は利用できます。設定方法は[データベース](database.md)を参照してください。

## 安全に使うための確認

- 実測データと説明用データを同じ名前で管理しない
- 方位が「吹いていく向き」であることを確認する
- m/sとkm/h、degreeとradianを区別する
- JSONを正式記録として保存し、出典、作成者、作成日時、用途を別途記録する
- 実機判断では公式気象情報と現地実測を確認する
